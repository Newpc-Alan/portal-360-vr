# Portal 360º VR

Portal de experiências educacionais 3D e realidade virtual do Portal do Educador / NEWPC.

## Estrutura
- `index.html`: abertura em vídeo + catálogo de experiências
- `apps/sistema-solar/index.html`: Sistema Solar 3D VR v7
